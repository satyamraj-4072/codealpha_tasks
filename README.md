# ☕ Java Console Applications

A collection of **Java console-based applications** developed to demonstrate core programming concepts, object-oriented programming (OOP), file handling, collections, and menu-driven application development. Each project is designed to solve a real-world problem while strengthening Java fundamentals.

---

# 📌 Projects Included

This repository contains the following Java applications:

1. 📚 Student Grade Tracker
2. 📈 Stock Trading Platform
3. 🏨 Hotel Reservation System

---

# 📚 Student Grade Tracker

## Overview

The Student Grade Tracker helps manage student academic records. Users can add students, record grades, and generate reports containing average, highest, and lowest scores, along with overall class statistics.

### Features

* Add new students
* Record multiple grades
* Calculate average marks
* Display highest and lowest marks
* Generate class summary
* Input validation
* Menu-driven interface

### Technologies

* Java
* ArrayList
* Scanner
* Object-Oriented Programming (OOP)

---

# 📈 Stock Trading Platform

## Overview

The Stock Trading Platform simulates a simple stock market where users can buy and sell predefined stocks, manage their portfolio, and monitor investment performance using a virtual cash balance.

### Features

* View market data
* Buy stocks
* Sell stocks
* Portfolio management
* Cash balance tracking
* Portfolio valuation
* Input validation

### Technologies

* Java
* HashMap
* Scanner
* Object-Oriented Programming (OOP)

---

# 🏨 Hotel Reservation System

## Overview

The Hotel Reservation System is a console-based application that allows users to search available rooms, book accommodations, cancel reservations, and manage booking records. Reservation details are stored in a text file for persistence.

### Features

* Search available rooms
* Book hotel rooms
* Cancel reservations
* View bookings
* Payment confirmation
* File handling using text files
* Menu-driven interface

### Technologies

* Java
* File Handling
* ArrayList
* Scanner
* Object-Oriented Programming (OOP)

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/java-console-applications.git
```

Move into the project directory:

```bash
cd java-console-applications
```

Compile any project:

```bash
javac Main.java
```

Run the application:

```bash
java Main
```
